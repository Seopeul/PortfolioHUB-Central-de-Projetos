# 🚀 PortfolioHUB • Central de Projetos

O **PortfolioHUB** é uma plataforma centralizada e funcional desenvolvida para exibir, gerenciar e organizar projetos digitais de forma limpa, responsiva e segura, totalmente integrada ao ecossistema GitHub.

---

## 📌 Sobre o Projeto

O objetivo principal do **PortfolioHUB** é servir como ponto de acesso único e profissional para o portfólio digital, permitindo a visualização rápida de repositórios, códigos-fonte e aplicações em produção.

### Destaques:
* **Interface Centralizada:** Design escuro moderno, focado em legibilidade e experiência do usuário.
* **Hospedagem Simplificada:** Publicação contínua utilizando **GitHub Pages**.
* **Suporte de IA:** Implantação e estruturação guiadas com o apoio da IA **Google Gemini**.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da aplicação.
* **CSS3:** Estilização responsiva e tematização escura integrada.
* **Git & GitHub:** Versionamento de código, controle de acesso e hospedagem estática.

## 🚀 Como Executar Localmente

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/Seopeul/PortfolioHUB.git
   ```

2. **Acessar a Pasta:**
   ```bash
   cd PortfolioHUB
   ```

3. **Visualizar:**
   Abra o arquivo `index.html` em qualquer navegador ou utilize a extensão **Live Server** no VS Code.
